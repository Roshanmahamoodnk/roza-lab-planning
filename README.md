# ROZA LAB reference library

Updated 3 October 2026. This is the compact References / Ideas / Plans frontend.

## Hosting
Extract the complete ZIP into the approved GitHub Pages root, `/docs` folder or subdirectory. Preserve the `evidence/` directory and every HTML, CSS, JavaScript and PNG asset. All paths are relative, so repository-subpath hosting works without a base URL change. `.nojekyll` is included. There is no build step, dependency installation, server, API key, payment or account configuration. No CNAME is supplied. Do not overwrite an unrelated existing website.

The main entry is `index.html`. The previous detailed planning presentation remains in `archive.html`. An existing business website can link to the successfully published library URL.

## Functionality
65 attributed reference records; 65 have verified captured post visuals; 0 remain text-only. Search and filters cover source brands, platforms and evidence status. Each card opens its source, observation, why it was referenced, date/performance limits, and linked original directions. Ideas contains 10 original directions. Plans contains 16 proposed October post families, 48 copy variants and their existing frames/video briefs. Caption copying and text-brief downloading work entirely in the browser.

This is read-only. Shared comments, uploads, new records, durable campaign saving and collaboration are not implemented, and the interface says so. No personal data is submitted or stored. Nothing is approved, scheduled or posted to social media. No localStorage is used as product data.
